# Security Policy

## Purpose

Recon Tool is an educational cybersecurity project designed to automate
reconnaissance tasks for authorized security testing, laboratories, and
learning environments.

## Responsible Use

This tool must only be used against systems and assets that you own or have
explicit permission to assess.

Unauthorized scanning, enumeration, or security testing may violate laws,
contracts, acceptable-use policies, or the terms of service of the target
system.

The author is not responsible for misuse of this software.

## How to Report a Security Vulnerability

If you discover a security vulnerability in Recon Tool itself, please report
it privately. Do not disclose the vulnerability publicly before it has been
reviewed and, when appropriate, addressed.

### Preferred method: GitHub Private Vulnerability Reporting

If enabled, use the repository's **Security** tab and select **Report a
vulnerability** to submit a private report through GitHub's security advisory
system.

This is the preferred reporting method because it provides a private,
structured channel for communication between the reporter and maintainer.

### Alternative method: Email

If GitHub Private Vulnerability Reporting is unavailable, please contact:

**[eupedrocarm01@gmail.com](mailto:eupedrocarm01@gmail.com)**

Please use the subject:

`[SECURITY] Recon Tool Vulnerability Report`

Please include:

* A clear description of the vulnerability
* Steps to reproduce the issue
* The affected component or file
* Potential security impact
* Any relevant logs or proof of concept
* Suggested remediation, if available

Please avoid including sensitive information that is not necessary to
reproduce or understand the vulnerability.

## Response and Disclosure

Reports will be reviewed privately.

The disclosure timeline may depend on the severity, complexity, and availability
of a fix. Reporters may be credited for their discovery when appropriate and
with their consent.

Please do not publicly disclose a vulnerability while it is being investigated
or before a coordinated disclosure decision has been made.

## Scope

This policy applies to vulnerabilities in the Recon Tool codebase.

Findings produced by the tool against third-party systems are outside the
scope of this repository's security policy.

## Development Status

Recon Tool is an active learning project and is still under development.

Security behavior, dependencies, output formats, and implementation details
may change between releases.
